Musa CAD is a fast, modern 2D drafting application. It follows AutoCAD's ribbon,
command line, prompts and shortcuts, so a drafter's habits carry over, and its
multi-threaded, GPU-accelerated core keeps large drawings smooth to pan, zoom and
edit. DXF is read and written natively; DWG goes through the free ODA File Converter.

## Getting involved

Bugs and feature requests go on [the issue tracker](https://github.com/MusaCAD/MusaCAD/issues).
Start with the [contribution guide](https://github.com/MusaCAD/.github/blob/main/CONTRIBUTING.md)
and [Code of Conduct](https://github.com/MusaCAD/.github/blob/main/CODE_OF_CONDUCT.md).
See [accessibility](https://github.com/MusaCAD/.github/blob/main/ACCESSIBILITY.md) for
known limitations and reporting options.
