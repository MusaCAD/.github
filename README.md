# MusaCAD community files

This repository contains the [organization profile](profile/README.md) and the
shared community policies and contribution templates used by MusaCAD repositories.
A repository can provide its own version when it needs more specific guidance.

- [Code of Conduct](CODE_OF_CONDUCT.md)
- [Contributing](CONTRIBUTING.md)
- [Security policy](SECURITY.md)
- [Accessibility](ACCESSIBILITY.md)

For the application and user documentation, visit [MusaCAD](https://github.com/MusaCAD/MusaCAD)
and the [Musa CAD wiki](https://wiki.musacad.org/).
